## 📐 How to Calculate Deck Boards (the formula)

The [deck board calculator](https://deckboardscalculator.com/tools/deck-board-calculator/) uses actual lumber sizes, not nominal ones. A "6-inch" deck board is really 5.5 inches wide after milling — using the nominal size is the #1 DIY ordering mistake.

**Step 1 — Rows across the deck width:**

```
rows = deck width (in) ÷ (actual board width + gap)
```

Standard gap: 1/8"–1/4" for pressure-treated pine, 3/16" for composite.

**Step 2 — Boards per row:**

```
boards per row = deck length (ft) ÷ board length (ft)
```

Round up, and stagger butt joints across rows.

**Step 3 — Add waste:**

```
total boards = rows × boards per row × (1 + waste %)
```

Use 10% waste for straight layouts, 15% for diagonal.

**Worked example — 12 × 12 ft deck, 5.5" actual boards, 1/8" gap, 12 ft boards, 10% waste:**

- rows = 144 ÷ (5.5 + 0.125) = 25.6 → 26 rows
- boards per row = 12 ÷ 12 = 1 → 2 with butt-joint stagger
- total = 26 × 2 × 1.10 = 57.2 → **58 boards**

Or skip the math: the [deck board calculator](https://deckboardscalculator.com/tools/deck-board-calculator/) does all three steps, including screw and hidden-fastener counts.

## 🪜 Deck Stairs in One Line

```
number of risers = total rise (in) ÷ 7.5   (round to nearest whole)
tread depth ≈ 10"–11"  ·  stringer length = √(total rise² + total run²)
```

The [deck stair calculator](https://deckboardscalculator.com/tools/deck-stair-calculator/) handles uneven ground and gives you the cut layout per stringer.

## 🧱 Concrete Bags Cheat Sheet

Each bag yields roughly:

| Bag | Yield |
|---|---|
| 40 lb | 0.30 cu ft |
| 60 lb | 0.45 cu ft |
| 80 lb | 0.60 cu ft |

Post hole volume = hole volume − post volume. The [post hole concrete calculator](https://deckboardscalculator.com/tools/post-hole-concrete-calculator/) does the subtraction for you; the [concrete bags calculator](https://deckboardscalculator.com/tools/concrete-bags-calculator/) converts any pour into bag counts.
